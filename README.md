# House Price Prediction ML Project

## Project Overview

This project predicts house prices using Machine Learning techniques and Linear Regression.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training
- Model evaluation
- House price prediction

---

## Problem Statement

The goal of this project is to build a Machine Learning model that can accurately predict house prices based on various housing features.

---

## Dataset Information

Dataset contains housing-related features such as:
- Area
- Number of rooms
- Location
- Overall quality
- Year built
- Garage area
- And more

Dataset used:
- train.csv
- test.csv

## How To Run This Project

1. Clone the repository

```bash
git clone https://github.com/aswinrajkt/house-price-prediction-ml.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Open Jupyter Notebook

```bash
jupyter notebook
```

4. Run the notebook
